# Tarea Procedimiento GitHub

Repositorio creado para practicar un flujo básico de colaboración utilizando GitHub.

## Objetivo

Aplicar el uso de Issues, ramas, commits, Pull Requests y Merge dentro de un flujo de trabajo sencillo.

## Flujo utilizado

1. Crear un Issue para registrar la mejora.
2. Crear una rama dedicada.
3. Realizar los cambios.
4. Registrar los cambios mediante commits.
5. Crear un Pull Request.
6. Revisar los cambios.
7. Hacer Merge hacia la rama principal.
8. Cerrar el Issue.
